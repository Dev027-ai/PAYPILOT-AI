## 1. PROJECT IDENTITY

Working name: **PayPilot AI**

Tagline: **Your money, understood.**

Product description:

PayPilot AI is an AI-powered payment and financial intelligence workspace that lets users express payment-related intentions in natural language, interact with available PayPal services, understand transaction activity, explore spending patterns, and complete supported purchases through a secure PayPal Sandbox checkout.

The AI must do more than generate conversational text. It should interpret intent, retrieve trustworthy data, call constrained tools, explain results, prepare actions, and coordinate supported payment workflows.

This is an independent hackathon project. Do not imply that it is an official PayPal application or that PayPal endorses it.

Keep the product completely separate from all medical, dental-tourism, and unrelated projects.

### B. AI CHECKOUT AGENT — THE MAIN DEMONSTRATION

This is the primary end-to-end workflow.

Build a small, attractive, self-contained demonstration storefront with a curated, original product catalog.

A user should be able to type:

"I need a wireless keyboard under $75. Find the best option and help me purchase it."

The agent should:

1. Understand the request and budget.
2. Search the application's trusted catalog.
3. Compare actual product attributes, price, and availability.
4. Recommend a suitable option and explain its choice.
5. Display a product card with the actual catalog price.
6. Prepare the cart.
7. Show the complete order summary and currency.
8. Validate the total on the server.
9. Ask the user to review and proceed.
10. Create a genuine PayPal Sandbox order.
11. Launch PayPal's supported buyer-approval checkout.
12. Capture the approved order on the server.
13. Verify the capture response.
14. Display the confirmed payment reference.
15. Save the order and verified payment status.
16. Refresh the order and transaction views.

Use current PayPal-supported checkout packages and APIs. Prefer the official React SDK v6 and server SDK, following the current guide:
https://developer.paypal.com/guides/nextjs-checkout

Suggested packages to verify against the current official documentation:
- `@paypal/react-paypal-js`
- `@paypal/paypal-server-sdk`

Important restrictions:
- The demonstration storefront is our own explicitly labelled Sandbox store.
- Never claim an external retailer order has been purchased merely because an external product was found.
- Never treat an AI response, frontend callback, redirect, or order-approval screen alone as proof of completed payment.
- Never let the model manipulate the final payable amount.
- Use server-controlled catalog pricing, order validation, and verified capture results.
- Never execute a payment without a clear user-controlled approval step.

The goal is to demonstrate a genuine, working purchase workflow instead of an AI recommendation that goes nowhere.

### E. AI INTERNATIONAL PAYMENT ASSISTANT

Provide a transparent international payment estimation interface.

Example:

"If I convert $500 to INR, approximately how much would that be?"

Support:
- Source amount and currency.
- Destination currency.
- Verified exchange-rate lookup.
- Rate source and timestamp.
- Estimated converted amount.
- Available, verified applicable fees.
- Estimated recipient amount only when the required data supports the calculation.
- Clear explanation of assumptions.

Use a reliable external exchange-rate service behind a replaceable provider adapter.

If live rates are unavailable, use an explicitly labelled demonstration rate.

Do not invent exchange rates, current PayPal fees, transfer eligibility, delivery times, or a guaranteed recipient amount.

Distinguish three concepts:
1. Indicative currency conversion.
2. An actual quote returned by a supported service.
3. An executable payment or remittance transaction.

A conversion calculation is not proof that PayPal supports sending money through that route.

Do not implement an unsupported peer-to-peer transfer by pretending that a checkout order is an international remittance.

If the required data is unavailable, explain the limitation in the UI.
